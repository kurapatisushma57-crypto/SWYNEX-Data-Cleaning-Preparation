# SWYNEX Data Cleaning & Preparation

## Project Overview

This project focuses on cleaning and preparing a public dataset for data analysis.

The Adult Census Income dataset was used for this task. The dataset contains demographic and employment-related information and an income category.

## Dataset

Dataset: Adult Census Income Dataset

Main columns include:

- Age
- Workclass
- Education
- Education Number
- Marital Status
- Occupation
- Relationship
- Race
- Sex
- Capital Gain
- Capital Loss
- Hours per Week
- Native Country
- Income

## Data Cleaning Steps

The following data cleaning techniques were performed:

1. Loaded the dataset using Pandas.
2. Added appropriate column names.
3. Identified missing values.
4. Replaced missing categorical values with `Unknown`.
5. Identified duplicate records.
6. Removed duplicate records.
7. Checked categorical values for consistency.
8. Checked and verified data types.
9. Performed a final data quality check.
10. Saved the cleaned dataset as `cleaned_dataset.csv`.
